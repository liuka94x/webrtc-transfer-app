Trasferimento file P2P

I file viaggiano direttamente browser-to-browser su WebRTC DataChannel (cifrato DTLS): nessun file passa da un server.

1 · Chi invia: genera il codice invito

2 · Chi riceve: incolla il codice e genera la risposta

3 · Chi invia: incolla la risposta per collegarsi

La stanza online usa la segnalazione WebSocket dell'app stessa (/api/ws): funziona sia dall'URL deployato sia in locale con mistral dev. La modalità manuale non richiede alcun server.
